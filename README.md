# Blogger Dashboard

Современный дашборд для блогера, построенный на Vue 3 с использованием Tailwind CSS.

## 🚀 Особенности

- **Vue 3 Composition API** - современный подход к разработке
- **Tailwind CSS** - утилитарный CSS фреймворк
- **Компонентная архитектура** - модульная структура
- **Composables** - переиспользуемая логика
- **Адаптивный дизайн** - поддержка всех устройств
- **Видео плеер** - интерактивные примеры работ
- **Темная тема** - современный дизайн

## 📁 Структура проекта

```
src/
├── components/           # Vue компоненты
│   ├── icons/           # SVG иконки
│   ├── BloggerInfo.vue  # Информация о блогере
│   ├── SocialNetworks.vue # Социальные сети
│   ├── StatsBlocks.vue  # Блоки статистики
│   ├── WorkExamples.vue # Примеры работ
│   ├── Reviews.vue      # Отзывы
│   ├── ErrorBoundary.vue # Обработка ошибок
│   └── LoadingSpinner.vue # Индикатор загрузки
├── composables/         # Vue composables
│   ├── useVideoPlayer.js # Логика видео плеера
│   └── useBloggerData.js # Данные блогера
├── utils/               # Утилиты
│   ├── constants.js     # Константы
│   └── helpers.js       # Вспомогательные функции
├── types/               # Типы данных
│   └── index.js         # JSDoc типы
├── assets/              # Ассеты
│   └── index.js         # Централизованные импорты
├── images/              # Изображения
├── video/               # Видео файлы
├── App.vue              # Главный компонент
├── main.js              # Точка входа
└── style.css            # Глобальные стили
```

## 🛠️ Технологии

- **Vue 3** - прогрессивный JavaScript фреймворк
- **Vite** - быстрый сборщик
- **Tailwind CSS** - CSS фреймворк
- **PostCSS** - обработка CSS
- **Autoprefixer** - автоматические префиксы

## 📦 Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd blogger-dashboard

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🎯 Основные компоненты

### BloggerInfo
Отображает информацию о блогере: аватар, имя, нишу и кнопку действия.

### SocialNetworks
Показывает социальные сети с количеством подписчиков.

### StatsBlocks
Блоки статистики: рейтинг, статус, завершенные сделки.

### WorkExamples
Интерактивные примеры работ с видео плеером.

### Reviews
Отзывы пользователей с рейтингом.

## 🎮 Функциональность

- **Видео плеер**: клик для запуска/паузы
- **Эксклюзивное воспроизведение**: только одно видео одновременно
- **Звук**: видео воспроизводятся со звуком
- **Адаптивность**: поддержка мобильных устройств
- **Обработка ошибок**: graceful error handling

## 🎨 Дизайн

- **Темная тема** с градиентными панелями
- **Стеклянный эффект** (glassmorphism)
- **Анимации** и переходы
- **Типографика** Inter
- **Цветовая схема**: синие оттенки с акцентами

## 📱 Адаптивность

- **Desktop**: 1920px+ (полная функциональность)
- **Tablet**: 768px-1024px (адаптированная сетка)
- **Mobile**: до 768px (вертикальная компоновка)
